YieldFit

Три метода аппроксимации кривой упрочнения σs(ei)

Рабочая точка

По умолчанию 1,568 (формула (303) при γ ≈ 8°).

Начальное напряжение

Предел текучести или экстраполяция левого участка.

Точки кривой

ei σs, МПа
Режим «точное решение»: должны быть ровно три точки.

Данные для метода Воронцова

σs(q) = A − B·e−q − C·e−N·q.
S0 — σs при q = 0.
S1 — σs при q = E1 (первая опорная точка).
S2 — σs при q = E2 (вторая опорная точка).
S3 — σs при q = E3 (контрольная точка, по ней подбирается N).
E1, E2, E3 — три независимые координаты; E3 не обязана быть самой правой или самой левой.
Пример из книги (с. 21, алюминиевый сплав АВ): S0 = 140, S1 = 240 при E1 = 0,4; S2 = 300 при E2 = 1,2; S3 = 210 при E3 = 0,2. Должно получиться A ≈ 349, B ≈ 163, C ≈ 46, N = 20.
